# 打赏二维码素材

当前使用哪一套见 [active.txt](active.txt)。这些归档不直接打进安装包，
只有选中的两张图片会复制到共享 UI，供 Android、桌面和 webOS 使用。

| 名称 | 标识 | 内容 |
| --- | --- | --- |
| 自由金额版 | `free-v1` | 2026-11-27 切换前、v0.2.183 使用的微信/支付宝无金额二维码，已去除姓名昵称 |
| 固定 20 元版 | `fixed20-v1` | 用户于 2026-11-27 提供的两张固定金额二维码，保留 ¥20.00、去除姓名昵称 |

以后只需说“切回自由金额版二维码”，不需要记应用版本号。
只切换二维码素材，不回退其他功能。

```sh
# 切回自由金额版
python3 scripts/select_support_qr.py free-v1

# 使用固定 20 元版
python3 scripts/select_support_qr.py fixed20-v1

# 校验归档与实际打包的两张图片一致
python3 scripts/select_support_qr.py --check
```

运行后提交两张共享图片和 `active.txt` 的修改，随下一次应用版本发布。
应用没有新增选择项、远程配置、支付统计或支付回调。打赏页和诊断扫码弹窗
继续共用原有图片路径，金额效果由作者根据实际收款自行观察。

个人信息清理只修改二维码下方的姓名文字区域；二维码、中心图案、金额和其余区域
均保留原图像素。原始含姓名图片不入库。处理时本机二维码识别验证前后内容一致，
但未发起真实支付。
