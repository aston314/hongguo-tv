# 红果播放解析规则

用于本项目的本地播放协议更新。JSON 由原生解释器自动加载；JS 是保留用户选择的可选应急路径。先识别当前授权的 `hongguo-tv` 源码仓库和分支，检查工作区改动；不要依赖以前聊天中的临时目录、设备地址或凭据。

字段／参数修复先读 `docs/playback-profile-authoring.md`，作为自动原生 JSON 的生成、分发和验收规范。JS 修复读取 `docs/playback-rule-authoring.md`，作为 JS 协议、生成、验收和发布的权威规范；`docs/playback-auto-repair.md` 记录功能行为与实测边界。如果文件尚未在当前分支，先查本地分支／已授权 PR，明确其集成状态，不据此宣称功能已发布。本文是执行入口，不复制详细协议以免两份规范漂移。

## 选择交付路径

- JSON schema 能表达的字段表、query、常量、白名单主机或请求体变化：优先准备原生 JSON 候选；使用 `profile_codegen` 同步基线，验证 Go／webOS 原生解释器。JSON 自动启用、启动检查，无新设置、用户自填地址或 JS VM。
- schema 表达不了的签名逻辑、注册、模型解析或来源编排变化：在现有宿主能力内准备 JS 修复候选。保留 `video_tab` 正常快路径与完整原生兜底。
- 需要新宿主能力、信任锚、播放器／媒体解密／UI 变化：客户端发版。
- Android 与桌面共用 Go 宿主；webOS 新增独立 Node 工作进程宿主，接收相同签名规则和通道。首次接入仍需应用升级；测试真实旧 Node、媒体与 LG 设备能力，不以 Node 兼容性代替电视验收。
- 目标是经验证后以规则更新承担日常取源修复。JS 默认关闭、JSON 自动启用及各自验收边界不因本 skill 改变，后续正常应用版本仍同步维护内置基线。

## 实现与生成

1. 先确认故障环节：上游空体、业务错误、签名、ID、ByteVC2 兼容来源、媒体或解码。不要拿 HTTP 200 或“有模型”当作可播放成功。
2. 编辑 `core/internal/jsresolver/source/` 的实际规则编排，或生成器明确复用的 `webos/service/` 模块／纯函数。补能重现问题的脱敏 fixture；复用模块有变更时检查 webOS 的兼容性与行为。
3. 在源码仓库根目录执行 `go run ./scripts/resolver_js_codegen`，再执行 `-check`。不得直接修改生成 bundle、手拼发布 JS 或把账号／播放器模块打进去。
4. 保持现有 `metadata`／`selfTest`／`resolve`、精确 ID、错误分类、宿主限制和原生回退合同。JS 负责协议；各平台宿主只提供既有字节原语、受限 HTTP 与规则管理，不引入远程解析服务或高层原生签名空壳。

## 验收

- 按权威规范运行生成检查、resolver／updater race 测试、应用回退测试和规则／公告 UI 测试。
- 使用 Go 内的真实宿主验证规则，而不只验证 Node。签名自测不得联网或伪造通过；大整数、域名／身份回退、业务错误、取消与仅 ByteVC2 的行为需要 fixture 证据。
- 实际取源时区分 JS 独立成功和原生回退成功；取得兼容编码、验证媒体／解密，再验证切集切剧。使用发布字节验证活动版本、更新／回滚／停用和重启缓存。
- 不以 CI、单集或高性能设备代替低端设备与长时间播放验收。性能对照分离冷／热、CPU／网络，检查连续播放内存走势；Goja 不提供硬堆配额，Node vm 不是敌对脚本沙箱，V8 old-space 限制也不是进程 RSS 上限。webOS 只在独立进程执行下载规则，并验证超时、关闭和服务退出的清理。
- 证据缺失就写明边界。原始设备报告、URL／Token／身份／密钥与内存原始数据不进入公共仓库或日志，只提交脱敏 fixture 与匿名结论。

## 发布与维护

先准备可审查候选。在用户对当前任务授权的范围内，使用现有 `resolver-rules.yml` 从允许的主线生成签名清单与不可变哈希模块，按工作流 `kind=js` 或 `kind=json` 分发到公开发布仓库的 `resolver-js/` 或 `resolver-profile/`；两个 product、缓存和控制 revision 独立。不混用实验通道，不手改签名，不将私钥写入文件或日志。

控制 revision 必须递增；脚本变化必须换模块版本。新清单有接受有效期，正常运营需要续签。紧急停用使用更高 revision 的签名控制，不能回放旧清单。公告仅引导并比对实际活动 revision，不传入可执行地址、不改变用户选择。

本 skill 不授予后续主线合并、稳定通道发布或应用 release 的常驻权限。任务只授权生成／验证时，完成候选及报告即可。交付时明确：提交／规则版本、独立取源与媒体证据、平台边界、候选或已发布状态，以及是否仍需客户端发版。
