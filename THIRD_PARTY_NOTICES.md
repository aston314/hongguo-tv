## Playback-v5 signing port

The following files adapt the playback-v5 implementation in
[N3urda/hongguoTV](https://github.com/N3urda/hongguoTV), commit
`18c37c2afd0567520135abcae312352542f09083`:

- `core/cmd/hongguotv/playback_v5_sign.go`

The three synthetic fixture files `signing-v5-{f13,carrier,wire}.json` in
`core/cmd/hongguotv/testdata/` were generated from upstream Kotlin tests using
synthetic input. They contain no registered production identity, account
credential, media address, or content key. The wire fixture fixes the process
clock at `1800000000000`, process nonce at `synthetic`, and random words at
`0x80000000`, covering all four timestamp-dependent carrier branches.


## Local playback resolver host

The optional rule's full device query, anonymous registration/activation and
expanded Medusa device envelope additionally adapt
[OOIUa/hongguo-android v0.8.0](https://github.com/OOIUa/hongguo-android/tree/12e373137e33f0155cbc33484dfdfdfa632c9906),
commit `12e373137e33f0155cbc33484dfdfdfa632c9906` (GPL-3.0-only):
`PlaybackDevice.java`, `MobilePlayerV5.kt`, and `Signer.kt`. The corresponding
sources are `core/internal/jsresolver/source/official-playback.js` and the
official-envelope functions in `webos/service/playback-v5-sign.js`.
`core/internal/jsresolver/testdata/signing-v5-official.json` was independently
generated by that Kotlin implementation with synthetic identity/nonce,
clock `1800000000000`, and random function `0.5`. These additional offline
vectors do not replace the four vectors understood by installed clients.

The optional local JS host uses Goja, goja_nodejs and their reachable dependencies.
Their license texts are included in `core/cmd/hongguotv/ui/third-party-licenses.txt`
and are embedded in the distributed core. The generated bundle in
`core/internal/jsresolver/resolver.js` retains the signing ports and attribution
described above. Its corresponding source is the allowlisted modules and
`scripts/resolver_js_codegen/main.go`.

## webOS signed rule worker

Ed25519 verification uses TweetNaCl.js 1.0.3 (Unlicense). The private legacy byte
adapter uses buffer 4.9.2 and base64-js 1.5.1 (MIT), and ieee754 1.2.1
(BSD-3-Clause). Published npm distributions were integrity-checked before
vendoring. Copies, full licenses and provenance under `webos/service/vendor/`
ship in the IPK. Only buffer dependency paths and its Array.isArray adapter are
changed; the cryptographic implementation is not modified.
