设置

侧边栏显示

选择导航栏的显示方式。默认显示菜单文字，也可以只显示图标以扩大内容区域。

界面语言

选择应用界面语言。切换后会重新加载界面。

推荐自动播放方向

只影响推荐页自动起播和自动接播。手动播放与历史续播不受影响；片源未提供画面尺寸时按原逻辑播放。

播放时隐藏侧边栏

从卡片进入单剧播放后隐藏左侧菜单。播放控件和自动清屏沿用现有逻辑，推荐页不受影响。

有声倍速（实验）

仅用于 webOS，默认关闭。开启后，倍速播放会额外读取音频并占用内存；准备失败或设备处理跟不上时恢复有声 1 倍速。

下一集预取方式

选择切集前的准备方式。边播边下占用较少；整集预下载切集更快，但会增加网络、存储和处理器占用。
