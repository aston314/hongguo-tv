# 本地 JS 播放解析器：Shield 验证（2026-11-20）

## 结论和范围

这条路线已通过真实算法、真实取源、媒体解密和 Shield 播放验证：可把播放
解析流程放进约 **71 KiB 的 `resolver.js`**，在设备本地运行，无需解析服务器。
不重装 APK、只替换脚本后，六个跨集／跨剧样本全部实际播出。

相比之前的 Go/WASM 解释执行原型，内存明显降低；仍有取源速度代价：本轮
同包逐样本对照，JS 比原生多 **660～880 ms**。因此本次成果是可运行的实验原型，
尚未启用正式版的在线脚本更新，也未合并主线或发布正式版本。

- APK：15,823,077 字节；安装后回读 APK，再次确认 SHA256 为
  `2adf8ecb27d1a2d4711250cb5cc997122121032c3dee9c78c5d013a36f73da5f`。
- JS：72,498 字节，版本 `2026.11.20.3`，SHA256 为
  `a63b6d56ccfcf6bacf37357a183a78fe667fd33baff65b0d140d2302a96cfa71`。

脚本复用 webOS 现有纯算法，包含匿名设备注册、TTEncrypt 组包及派生、V5 签名与
carrier 运算、身份状态、模型及密钥解析、ByteVC2 的兼容编码回退。
Goja 宿主只提供通用哈希、AES、gzip、随机数及受限 HTTP，不向 JS 暴露原生
注册器、签名器或解析器。JS 模式关闭原生解析回退。

标准 SM3 哈希交给 Go 加速，协议专用运算仍在 JS。没有该通用能力的旧宿主会保留
纯 JS 哈希；独立签名向量验证两者结果一致。最终 Shield 健康状态确认
`native_sm3=true`、`wire_vectors=4`、`embedded_fallback=false`。

正式程序入口没有导入 Goja；适配器由实验 build tag 隔离。当前没有修改正式版
的更新地址、信任密钥或播放路径。

## 内存：记录波动，不把某个快照当固定开销

以下均为整个 Go 核心进程，包含媒体准备等工作，不是独立的 JS 堆。

| 最终同包对照 | 原生 KiB | JS KiB |
| --- | ---: | ---: |
| 启动后、播放前 PSS | 14,098 | 20,582 |
| 六个样本后 PSS | 20,278 | 38,500 |
| 测试期间峰值 RSS（`VmHWM`） | 60,888 | 64,776 |

启动时新增约 6.3 MiB；本轮核心进程峰值 RSS 为原生约 59.5 MiB、JS 约 63.3 MiB。
PSS 和峰值 RSS 是不同指标，不能互相替代。先前同包 V2 对照的播放后 PSS 为
原生 59,680 KiB、JS 64,561 KiB，说明 GC、页回收、下载时序确实影响快照。
因此不能把其中任意一次差值称作长期固定开销。

先前精简 WASM 诊断版播放后核心进程 PSS 为 206,832 KiB，详细见
[WASM 拆分验证](playback-resolver-split-validation.md)。该原型工具链和二进制不同，
只作历史背景，不据此计算严格的生产版节省比例。完整 App 的 Java / WebView /
系统解码器内存没有被这些核心进程数字替代。

本轮未强制 GC，也没有通过六段短播放宣称不存在泄漏或适配全部老盒子。

## 只换脚本的实证和失败记录

第一版脚本的两次 Shield 冷启动各六个样本均返回空正文，原始失败报告保留在
证据 JSON。核对真实注册请求发现：JS 对 query 中 `*` 的编码与原生不同；
新增独立对照测试同时检查 query、TTDecrypt 后的设备档案和时间戳。

修正注册编码及 fallback User-Agent 日期后，把 V2 脚本放入同一 APK 的私有
测试目录。健康状态确认 `private_override=true`、版本 `2026.11.20.2`、SHA256
`f82bd69893646cd9528f71fd2b7b8fe1210c6cc8f72fb56c6e976aa19d2bf4cd`，
并实际播完六个样本。APK 回读 SHA256 仍为
`9acbf39927985f4fa4d7a94dadebda544d15c3efa96568e634b0c80e59f0e6ab`，
与首个 GitHub 构建一致。这证明替换脚本能改变真实解析行为，不是更改版本标签
或调用原生兜底。随后最终 V3 APK 的六段播放也通过。

注册编码差异已被实证并修正；不能据后续成功就认定所有历史空正文均由它造成。
上游长期稳定性仍需持续实测。原生参考的独立解析器刷新冷却为十分钟，JS 使用
三十秒；本轮干净成功批次未覆盖这一策略差异。

回滚、桌面宿主集成、webOS 实机及低性能 Android 盒子验收。用户不需要手填
清单地址；后续若接入正式更新，应沿用应用内置地址和既有代理选择机制。

本次私有文件激活使用一次性测试密钥，复用了现有签名／摘要校验流程，不能
称作正式在线更新已完成。Goja 有调用取消和 IO／栈上限，没有隔离的硬堆配额；
仅适合受审查并验签的模块。

安全证据在 [resolver-js-shield-20261120.json](evidence/resolver-js-shield-20261120.json)，
不含播放 URL、密钥或签名请求头。测试结束已停止本轮应用及子进程、删除下载
