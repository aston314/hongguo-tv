# Android TV 首页频道

Android 8.0 / API 26 及以上，应用向系统 `TvProvider` 发布一个默认频道「红果精选」。频道最多保留 20 条当前推荐，使用推荐接口已有的标题、简介和封面。Android 6、7 和 7.1 继续运行主应用，但不会使用旧版通知式推荐行。

节目卡片只保存剧集 ID，不保存签名播放地址。系统启动应用时，`hongguo://play` 深链会优先进入剧集播放；应用启动后仍通过现有 Go 详情与播放接口解析当前有效视频源。首页频道创建或更新失败（例如设备没有可用的 TV Provider、权限被系统撤销）只会跳过频道同步，不阻止应用启动和播放。

频道由系统 TV Provider 初始化广播和 Activity 启动时幂等创建。应用不会因为开机或更新广播启动常驻核心服务；只有用户打开应用或从频道深链进入时才启动核心。节目以剧集 ID 稳定更新；系统发出用户移除节目事件后，应用删除该记录并在本机保留抑制标记，后续推荐同步不会重新插入。应用数据清除会同时清除该标记。

标准版和 MPV 版具有不同 application ID，各自创建系统频道。如果两版同时安装，系统可能显示两条同名频道；通常只安装实际使用的版本。系统桌面可隐藏、移动或不显示频道，厂商桌面也可能不实现 Android TV 首页频道，因此 APK 构建成功不代表每台电视都会显示。

验证：Android 单元测试覆盖 API 版本门槛、剧集 ID 校验和频道节目数量上限；Gradle 构建验证 AndroidX TV Provider API 与两个播放器版本的打包。实际频道显示、封面抓取和遥控器点击仍需 Android TV 真机或具备 TV Provider 的模拟器确认。
