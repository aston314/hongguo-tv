# 可重复使用的手机找剧

Android 与 webOS 的“找剧 → 扫码输入”提供可收藏的局域网手机页面。手机提交剧名后，电视复用现有搜索流程，手机页面仍可继续发送其他关键词。桌面版不启用；手机号、验证码、弹幕仍使用原有一次性扫码输入。

## 使用边界

- 电视应用需处于前台且停留在“找剧”。进入播放器、切换栏目或进入后台时停止接收；详情等弹窗打开期间暂停接收。
- 关闭二维码弹窗不关闭手机入口，返回“找剧”会重新启用同一地址。电视停止心跳 10 秒后入口失效，过期会话不能自行恢复。
- 重启应用后复用私有目录 `phone-search.json` 中的随机入口和端口。手机与电视需在同一局域网；电视 IP 改变、清除应用数据或保存端口被占用后需重新扫码。应用关闭时不能访问，不提供公网域名或跨网发现。
- 新入口创建失败时，二维码弹窗回退到原有五分钟一次性输入。保留遥控器和系统输入法的原有路径。

## 协议与隔离

应用本地接口 `/api/v1/search/phone` 管理短期会话，手机只能访问独立 LAN 监听器的 `/search/<随机入口>/`、`mobile.js` 和 `state`，不能访问账号、历史等核心 API。入口使用 32 字节随机值，持久化权限为 `0600`。

每次激活更新会话与表单 nonce，每次提交后轮换 nonce。仅允许一个待接收关键词，以编号确认和去重；关键词只存在内存，不记录到日志。提交限制为 100 个 UTF-16 单元，并验证来源、Host、路径、JSON 及长度。慢速手机上传不会阻塞电视取消，上传完成后再次检查会话。

Android 使用 Go 服务，webOS 使用 Node 服务；两端共用手机 HTML、脚本和电视控制器。手机页支持简体中文、繁体中文和日语。

## 验证

- Go 普通及竞态测试覆盖重复发送、确认、重启复用、端口冲突、会话过期、边界隔离与慢请求取消；Node 服务有对应行为测试。
- 共享前端测试覆盖页面/后台取消、重复结果、迟到响应、弹窗门控及异常回退；webOS staging 检查共用手机资源没有遗漏或分叉。
- 本地真实 Go 核心与两张独立浏览器页面验证真实搜索、连续提交、离开/返回找剧及同地址复用。浏览器用 Android 标识模拟平台与前台条件，此结果不代表 Android 或 LG 真机验证。
