## 季结束

本季确认完整集列表并播放完最后一集后，先读取官方“系列剧”完整季列表，按当前季号精确查找第 N+1 季。跨季关系接口只在完整列表未提供当前季号时补充当前季号，不再阻断已经成功的完整列表；它返回的候选项不能覆盖列表中的严格相邻季。下一季待上线时不会绕过它去自动播放更后面的季。当前季号不明、季列表有缺口或下一季重复时停止自动跨季。

- 已上线且可播放：自动从下一季第1集播放。
- 待上线、有准确预约 item_id、未预约、已登录：弹出“预约下一季？”确认，默认焦点在“稍后”，用户确认才提交。
- 已预约：提示等待上线，不重复提交。
- 游客：提示登录后从“选集 → 系列剧”预约，不发送预约请求。
- 未开放预约/禁播：显示对应状态，不播放预告、不猜预约 ID。
- 请求失败保留确认框供重试；重复点击只提交一次；成功刷新本地系列状态并让预约/日历下次重新读取。

隔离 fixture 验证第13季第80集→预约第14季，稍后不写、失败可重试、成功回播放器焦点、已预约不写、游客不写，以及第12季结束自动第13季第1集。模拟旧接口返回第15季可播放时，完整系列中的待上线第14季仍优先预约。

## 缺少资料的旧剧

完整记录恢复后，旧剧资料接口单独请求返回业务错误 101000。资料是补充信息，不再阻断已完整读取的历史/收藏及进度上传：保留已有卡片或标记待补全，后续同步重试。请求取消和明确的剧集身份错配仍中止合并；分页或会员身份读取失败仍不能当作完整快照。新增回归覆盖资料失败仍保留收藏并成功上报播放进度。
