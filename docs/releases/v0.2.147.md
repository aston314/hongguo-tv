# 红果短剧 v0.2.147

本次发布按 `hongguo-player v1.2.20` 严格修正播放地址获取链路，重点降低推荐播放和切集时 `VIDEO_MODEL_EMPTY`、空播放信息及错误片源导致的失败。

- 播放请求改用 `api5-normal-lq` 协议，请求体 gzip 压缩，并对实际压缩字节签名。
- `VIDEO_MODEL_EMPTY`、缺少 `video_model`、空 `video_list` 和业务码 `110001` 统一识别为当前 `vid` 的流缺失，避免把一次空响应误当成永久失败。
- 同一身份先对同一个 `vid` 做有限确认；确认仍失败后，最多验证四个匿名候选身份，只有候选身份成功返回同一 `vid` 的片源才会替换当前身份。
- 恢复任务按 `vid` 合并、设有冷却和次数上限，预取与前台播放共享结果，不再在生产环境并发竞速六条线路。
- 播放内容类型贯通整集、Range、清晰度切换、预取、Range 地址刷新和身份恢复；媒体缓存 key 同时隔离清晰度、播放模式、解码模式和 `content_type`。
- 保留默认播放、MPV、标准版、桌面版和 webOS 的既有播放器策略，不改变登录、账号和 UI 行为。

本机验证已通过 Go 普通/生产标签测试、race、vet、全部 Node 回归测试，以及真实上游播放协议探针。浏览器预览中已验证推荐播放、切剧、切集和本地完整/Range 播放取源。Android、MPV、桌面和 webOS 安装包由 GitHub Actions 构建，仍需用户设备验收。
