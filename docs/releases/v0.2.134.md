# 红果短剧 v0.2.134

统一发布 Android 标准版、MPV 版、macOS、Windows、Linux AppImage 和 LG webOS 测试包。

- 修复同一部剧切换上下集时再次显示整剧海报的问题，覆盖普通切集、连续快速选集和准备中再次选集；优先复用按目标 VID 匹配的下一集预览图，保留原有上一帧过渡及有界的加载提示。
- Android 标准版根据当前片源的已知编码检测 WebView 支持情况；明确不支持时直接使用现有 Media3 播放，不再先等待 HTML5 失败。编码未知或支持情况不明确时保留原有流程，MPV、桌面和 webOS 不改变播放器选择。
- 修复播放诊断沿用上一集、上一次播放路径或历史原生播放器告警的问题；诊断只关联当前播放会话，当前有效的解码告警仍保留。
- webOS 获取播放信息遇到空响应时，最多请求 3 次，重试间隔为 250 毫秒、1000 毫秒，与临时 HTTP/网络错误共用次数预算；避免服务端恢复失败后页面再叠加一轮自动重试，手动重试仍可开启新一轮。
- webOS 播放准备失败显示错误码，诊断补充当前请求的阶段、上游 HTTP 状态、响应字节数及尝试次数；预取和旧请求不再覆盖当前错误，取消预取不影响已有的前台等待。
- Linux 打包工具使用固定版本和校验值，避免上游滚动构建变动导致下载校验失败。

## 平台包

- Android 标准版：`hongguo-tv-0.2.134.apk`（versionCode 133）
- Android MPV 版：`hongguo-tv-mpv-0.2.134.apk`（versionCode 85）
- macOS / Windows：`hongguo-desktop-0.2.134-macos-universal.zip`、`hongguo-desktop-0.2.134-windows-x64.zip`（桌面更新版本码 71）
- Linux x86_64 AppImage：`linux-v0.2.134-test.1` 预发行版
- LG webOS：`webos-v0.2.134-test.25` 测试版

保留现有扫码/手机号登录、下一集预取设置及 MPV 音频配置。webOS 继续使用唯一 HTML5 主视频元素与 Range 边播边下；有限重试不能解决持续的上游故障。Linux 包通过 Ubuntu 24.04 与 Debian 12 容器中的真实视频检查后发布；自动化构建与界面验证不代替各型号电视的实机验收。
