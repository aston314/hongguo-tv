# 红果短剧 v0.2.132

统一发布 Android、macOS、Windows、Linux AppImage 和 LG webOS 测试包。本版本包含播放切集过渡和追更提醒界面修复。

- 桌面 HTML5 同剧切换不再显示当前剧海报，保留播放器过渡状态，等待目标集真实画面接管。
- Android 推荐切换到另一部短剧时直接准备目标剧封面，避免先闪回当前剧海报。
- MPV 软件解码在健康的连续切集时复用播放器实例，硬件解码路径保持原有生命周期。
- webOS 为 HEIC 封面补充官网 JPEG CDN 回退地址，保留原签名封面地址。
- 更新提醒改为接近排行榜的可播放卡片，显示封面、集数、简介和热度信息；支持直接播放或打开详情。
- 更新提醒卡片使用独立的播放/详情焦点动作，方向键切换时会自动保持卡片完整可见，刷新后恢复原焦点。
- 更新提醒本地记录仅保存卡片展示和播放所需的元数据，不持久化完整媒体集数或视频源列表。
- webOS 继续使用原有 HTML5 播放和边播边下策略；本次切集封面改动不改变 webOS 播放路径。

## 平台包

- Android 标准版：`hongguo-tv-0.2.132.apk`（versionCode 131）
- Android MPV 版：`hongguo-tv-mpv-0.2.132.apk`（versionCode 83）
- macOS / Windows：`hongguo-desktop-0.2.132-macos-universal.zip`、`hongguo-desktop-0.2.132-windows-x64.zip`
- Linux x86_64 AppImage：`linux-v0.2.132-test.1` 预发行版
- LG webOS：`webos-v0.2.132-test.25` 测试版

Windows 播放 HEVC 视频需要系统解码扩展；商店无法获取时可参考 [HEVC Video Extensions 第三方仓库](https://github.com/Ayx03/HEVCVideoExtension)。
