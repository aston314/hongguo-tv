# 红果短剧 v0.2.131

统一发布 Android、macOS、Windows、Linux AppImage 和 LG webOS 测试包。本版本修复 MPV 软件解码播放器复用的 Android 编译问题，并继续包含 MPV 播放稳定性、媒体缓存隔离、视频尺寸识别、片源能力筛选和推荐自动播放方向设置。

- MPV 软件解码在连续切集时复用健康的播放器实例，减少重复创建和销毁解码器；硬件解码继续使用原有生命周期。
- 推荐页自动起播会记住上一部成功播放的剧，下一次自动起播优先选择不同剧；手动播放、失败播放和历史续播不受影响。
- 媒体准备缓存按播放器模式、读取模式和 codec 模式隔离，避免软件/硬件解码或 Range/整集准备误用不兼容缓存。
- 播放信息向页面传递视频宽高；推荐自动播放可在设置中选择全部剧、仅横屏剧或仅竖屏剧。方向筛选只作用于推荐页自动起播和自动接播，尺寸未知时保留原逻辑，最多检查 8 个候选。
- MPV 软件解码会过滤 bytevc1/bytevc2 不兼容片源；自动解码保留可交给硬件能力判断的候选，找不到兼容片源时返回明确错误。
- Android 的推荐方向设置使用原生偏好桥接持久化；桌面、webOS 和浏览器预览沿用各自本地设置存储。
- 继续保留标准版、MPV 版和桌面版的下一集预取设置；webOS 继续固定使用边播边下。

## 平台包

- Android 标准版：`hongguo-tv-0.2.131.apk`（versionCode 130）
- Android MPV 版：`hongguo-tv-mpv-0.2.131.apk`（versionCode 82）
- macOS / Windows：`hongguo-desktop-0.2.131-macos-universal.zip`、`hongguo-desktop-0.2.131-windows-x64.zip`
- Linux x86_64 AppImage：`linux-v0.2.131-test.1` 预发行版
- LG webOS：`webos-v0.2.131-test.25` 测试版

Windows 播放 HEVC 视频需要系统解码扩展；商店无法获取时可参考 [HEVC Video Extensions 第三方仓库](https://github.com/Ayx03/HEVCVideoExtension)。
