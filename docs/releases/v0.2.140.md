# 红果短剧 v0.2.140

本次重点恢复标准版在低端 Android 设备上的轻量播放路径，并减少播放期间的重复界面刷新。Android 标准版、MPV 版、macOS / Windows、Linux AppImage 测试版和 webOS 测试版均从同一主线版本构建。

- Android 标准版恢复 0.2.136 的播放逻辑与 Media3 1.8.0，移除新增 NextLib/FFmpeg 视频软解及相关 native libraries，减小安装包。
- 继续以 HTML5 为主播放，保留 `b399c94` 的有界 Media3 回退、经首帧验证的本地播放器偏好、播放位置传递和失败退出机制；系统解码器选择、兼容模式及 Android 6 PCM 音频处理恢复到 136 的策略。
- 保留新版登录、界面、焦点、预下载、切集过渡、竖屏背景及其它已合入的修复，不将整个应用降级到 136。需要额外软件解码能力时仍可选择 MPV 版，MPV 的播放器、解码策略和音频补偿不变。
- 播放控件仅在内容变化时刷新；控件隐藏期间跳过无用的视觉更新，显示时同步当前状态，减少弹幕播放时的 DOM 写入和渲染负担。弹幕运动、进度保存、下一集预取和切集行为不变。
- 修正桌面发布工作流读取附注标签时的冲突，校验远端标签对应提交后构建，不修改既有标签。

## 平台包

- Android 标准版：`hongguo-tv-0.2.140.apk`（versionCode 139）
- Android MPV 版：`hongguo-tv-mpv-0.2.140.apk`（versionCode 91）
- macOS / Windows：`hongguo-desktop-0.2.140-macos-universal.zip`、`hongguo-desktop-0.2.140-windows-x64.zip`（桌面更新版本码 77）
- Linux x86_64 AppImage：`linux-v0.2.140-test.1` 预发行版
- LG webOS：`webos-v0.2.140-test.25` 测试版

播放器回退及控件优化已通过 GitHub CI 和自动化检查；控件优化曾在 Shield 的现有调试页面作对照验证。标准版回退后在小米等问题设备上的播放效果仍待反馈，不将 CI 结果等同于多设备实测，也不宣称本次已修复切清晰度后无声等其它问题。Linux 测试包通过既有两种发行版容器播放检查后发布。
