# 红果短剧 v0.2.145

本次发布修复播放地址主目标与备用目标并发竞速时的响应归属问题。

- 播放地址请求为每次解析建立独立的有界目标竞速上下文。
- 较慢的旧目标响应不会覆盖已经选中的播放地址，也不会把已取消请求的结果写回当前播放流程。
- 保留播放签名、匿名身份恢复、官方备用地址、取消机制和现有播放器配置。
- 未改变 Android 标准版、MPV、桌面版和 webOS 的播放器选择、解码设置及 UI 行为。

## 平台包

- Android 标准版：`hongguo-tv-0.2.145.apk`（versionCode 144）
- Android MPV 版：`hongguo-tv-mpv-0.2.145.apk`（versionCode 96）
- macOS / Windows：`hongguo-desktop-0.2.145-macos-universal.zip`、`hongguo-desktop-0.2.145-windows-x64.zip`（桌面更新版本码 82）
- LG webOS：`webos-v0.2.145-test.26` 测试版
- Linux x86_64：`linux-v0.2.145-test.1` 独立 AppImage 测试版；仅在本次标签构建的 Ubuntu 24.04 / Debian 12 真实播放检查通过后发布。

自动化验证不替代所有盒子、电视和桌面设备的实机验证。Linux 与 webOS 继续使用测试渠道。
