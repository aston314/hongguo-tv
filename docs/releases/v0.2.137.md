# 红果短剧 v0.2.137

统一发布 Android 标准版、MPV 版、macOS、Windows、Linux AppImage 和 LG webOS 测试包。

- Android 标准版改为 Media3 优先播放：平台解码器优先；首帧前遇到解码错误或轨道能力超限时，最多尝试一次 NextLib FFmpeg 软件解码，仍失败则回到 HTML5。MPV 版播放路径不变。
- 标准版升级到 AndroidX Media3 1.11.1 和 NextLib Media3 Extensions 1.11.1-0.17.0。构建使用 compileSdk 36、targetSdk 35；最低 Android 6/API 23 不变。
- 桌面及 Android 8/API 26 以上可选动态模糊背景延伸，默认保持黑色；webOS 和较旧 Android 继续使用黑边，不改变视频画面、解码器或预取策略。
- webOS 对连续空播放响应使用有限预算的匿名身份恢复；不切换登录账号。Android、桌面和 Linux 保留已有的身份恢复策略。

Android 标准版的 Media3/FFmpeg 路径通过远端 CI 编译、单元测试、lint 和 APK ABI/Flavor 隔离检查；这些自动检查不等同于 Android 8/9 盒子、Android 9/13 设备或普通手机的实机播放验证。

- LG webOS：`webos-v0.2.137-test.25` 测试版

切集、媒体范围读取及既有设置保持原有行为。新版本请按设备当前安装的版本选择相同渠道覆盖更新。
