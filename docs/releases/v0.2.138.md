# 红果短剧 v0.2.138

本次发布 Android 标准版和 MPV 版。桌面版与 webOS 版本不变。

- Android 标准版默认播放恢复为 HTML5。HTML5 明确不支持片源、发生解码错误，或在限定时间内没有播放进展/首帧时，才转入 Media3；切换时保留播放位置。
- Media3 优先使用设备解码器。只有首帧前遇到明确解码错误或轨道能力超限时，最多尝试一次软件解码；仍失败则回到 HTML5，避免重复重试。
- 保留按 WebView 版本隔离且有有效期的本机 Media3 偏好。仅在 HTML5 已确认解码/格式失败、且 Media3 实际输出首帧后记录；Media3 失败时清除偏好。
- MPV 版没有播放器行为变更，仅随统一版本更新。

## 平台包

- Android 标准版：`hongguo-tv-0.2.138.apk`（versionCode 137）
- Android MPV 版：`hongguo-tv-mpv-0.2.138.apk`（versionCode 89）

标准版的 HTML5/Media3 路径通过远端 CI 编译、单元测试、lint 和包隔离检查；自动化检查不等同于多型号 Android 设备的实机播放验证。桌面版和 webOS 不在本次发布范围内。
