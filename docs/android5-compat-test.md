# Android 5 兼容性测试 · test.1

仅供 issue #112 的 Android 5/API 21 设备验证，基于正式版 0.2.136。
这是独立实验分支的标准版测试包，尚未合入 main，不代表正式支持 Android 5。
实验不接入正式在线更新，不改变正式版本、README 下载入口或更新 JSON。

## 下载与安装

- `hongguo-tv-android5-test.1.apk`：通用包，包含 ARM64、ARMv7、x86_64。
- `hongguo-tv-android5-test.1-arm32.apk`：仅 ARMv7 的排查包。当通用包仍在 ART/dex2oat 安装阶段失败时，可在支持 32 位 ARM 的系统上试用；这不能证明或保证修复固件问题。
- 两包都是非 debug APK，沿用现有签名，独立包名 `rocks.aston.hongguotv.android5test`，可与正式版共存；两个测试包之间使用相同包名，任选其一安装。
- 测试版名称为“红果短剧 · Android 5 测试”，账号、历史、设置独立，不读取正式版数据。关闭测试版开机自启和正式在线更新，卸载不会删除正式版数据。
- APK 是从源码面向 API 21 重建，包含 Go 原生内核，不是修改正式 APK 的 Manifest 后重签。

## 请按顺序反馈

1. 能否安装，安装哪一个 APK；失败请提供 ADB 完整错误和对应 `logcat` 安装片段。
2. 能否冷启动进入页面、遥控操作、搜索。
3. 能否播放一集、手动切集、自然连播、暂停恢复、退出重开。
4. 电视具体型号、Android 版本、`ro.product.cpu.abilist`、WebView/Chromium 版本；播放失败补充剧名和集数。

不要提供 Cookie、登录票据、手机号等敏感信息。安装失败与播放失败请分开描述；现有 `boot.art` / `boot_class_path_` 断言不足以证明 MultiDex 是根因。

CI 会核验包名、API 21、旧系统需要的 v1 签名、三 ABI/ARM32 隔离和 DEX 035，并在 API 21 模拟器验证安装、真实 Go 内核启动、WebView UI 初始化和强制停止后重开。模拟器通过不等于这台电视的硬件解码已验证。
