# 选集面板：系列剧

2026-10-07。独立 TV APK 内置 Go 8797 接入 Mac v1.1.6 的官方同系列选择器；APK 由 GitHub Actions 构建。

## 协议证据

静态分析原版 `hg-go/pkg/hgapi.(*Client).SeriesSeasons`、`rawSameIPSeason.model` 与 API 注册表，确认 GET `/reading/bookapi/plan/v`。注册方法为 GET，签名使用账号客户端已有的完整签名，附加已保存的会话；游客使用匿名设备身份。

完整 query：

```text
scene=10
from=single_col_same_ip_series
offset=0
limit=0
total_chapter_num=0
current_chapter_num=0
post_id=0
is_horizontal_screen=false
bookstore_tab=0
bookstore_tab_type=0
book_id=<当前 series_id>
filter_ids=<当前 series_id>
```

读取 `data[].video_data[]`，保持官方顺序，按字符串 series_id 去重。季标签来自 `secondary_info_list[].content`，副标题来自 `sub_title_list[].content`，不猜测标题。该选择器返回完整系列，包括当前季，不使用普通列表的递增 offset 分页。

存在 `subscribe_item`、首集 VID 缺失或零集都属于待上线；`disable_play` 的已上线项不可播放。待上线项即使带有预告 VID 也不会进入播放链路。预约必须使用 `subscribe_item.item_id` 的精确有效非零字符串值，没有 item_id 就不提供预约操作。只在上游成功后更新 `is_subscribed`；既有 POST `/api/v1/reservation` 接入已确认的 `uncover_subscribe/v`，不新增写协议。

本地 GET `/api/v1/series/seasons?series_id=<id>` 返回 `{ok,data:{items:[...]}}`。继承回环/同源限制和账号 generation 检查，失败与有效空列表分别处理，不缓存失败或空结果。

匿名只读实测《万妖图录传》第十三季：14 条，第1–13季可播放，第14季零集、无 VID、预计11月上线，可预约。当前第13季也在列表中。没有提交真实预约。

2026-10-28 对《借势千秋》做只读核对：完整系列列表返回第2季144集、第3季133集，以及带有效预约 ID 的待上线第4季；`from=series_short_play_info` 关系接口对第2、3季各连续3次返回空响应。没有执行预约写入或切换真实媒体。自动续季现以完整系列列表为主，关系接口失败不会挡住列表中已确认的相邻季或预约季。

## TV 面板与播放

- 选集面板提供“选集 / 系列剧”页签，进入系列剧才读取列表。
- 每季为一个可聚焦整行，显示封面、标题、官方季标签、副标题和状态。当前播放季高亮；已观看的其它季显示“继续播放”，未观看季显示“播放”。
- 页签左右移动，向下进入当前季；列表上下逐行滚动，首行向上回页签，向左也回系列剧页签。页签向上进入关闭按钮。返回关闭面板，恢复实际选集入口。
- 切换季先读取该季完整详情，失败保留原播放状态；详情成功后才解析选中的集，恢复该季历史进度。推荐页替换当前槽位，独立播放页保留原页面/卡片返回位置，面板继续打开并更新选集。
- 关闭面板、切回选集、退后台、换账号或播放对象已改变时，忽略迟到的详情，不自动起播。用户手动切季优先于同时发生的本集结束事件。
- 自动下一季优先使用已验证的 `from=single_col_same_ip_series` 完整系列选择器：当前季结束后按严格的 `season_index + 1` 找下一季，从下一季第1集、0秒开始；待上线季先进入预约流程，绝不跳过它。只有完整选择器没有当前季季号时，才用 `from=series_short_play_info` 关系接口补齐当前季号；关系接口失败不再阻断已经完整返回的系列列表。自动跨季会更新系列剧的当前标记，保留现有行节点与焦点。
- 待上线季提供预约/取消预约；不可用季仍可聚焦阅读状态。游客提示先到“我的”登录，保留面板和播放；不发送写请求。提交时保留焦点，重复点击不重复提交，失败不虚报成功，也不自动重试。预约结果同时刷新其它栏目显示。
- 状态提示固定在面板底部；季列表独立滚动，长列表的成功/失败提示不会落到不可见的最下方。
