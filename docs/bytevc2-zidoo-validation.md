# ByteVC2：Zidoo X9S / ARMv7 实测（2026-11-09）

## 结论

MPV 实验库能在这台比 Shield 弱的 Android 6 盒子上直接软解 ByteVC2 并出正常画面。
但 **720P 是兜底上限，不是每台旧设备、每段视频都流畅的保证**。同一集从头采样约
38 秒，720P 渲染掉帧 66 帧，540P 档只有 6 帧；后者的实际尺寸为 1024×576。
更低的真实片源有观看价值，应保留，而不是仅提供 720P。

产品方向仍是：原有三路先寻找可播放的 HEVC/H.264 兼容源；最终只有 ByteVC2 时，
MPV 再评估实际存在的 720P 及以下直接软解，暂不开放 ByteVC2 1080P。
不把 1080P 缩小显示冒充低清源，不把重转 H.264 作为本次结论。

该结论记录在独立实验分支；正式 MPV 仍需集成实验解码库及兼容选源策略。
本轮不修改正式播放逻辑，不合并主线，不发布正式版本。

## 性能对照

下表三组均以 2 秒间隔采样，测量窗口内不截图；仅保留新会话正确尺寸且状态为
`playing` 的点，剔除切源初始残留诊断。掉帧是 MPV 的渲染掉帧计数，不等同于
单独的 CPU 解码耗时，也不能据此把瓶颈归因于算法或硬件某个部件。

| 样本 | 实际尺寸 / fps | 有效媒体时间窗口 | 渲染掉帧累计 | 最大采样音画时钟偏差 |
| --- | --- | --- | --- | --- |
| 实际取源：第二集，720P | 1280×720 / 30 | 0.167～37.567 秒 | 0→66 | 约 110ms |
| 实际取源：同一集，540P | 1024×576 / 30 | 0.333～38.400 秒 | 0→6 | 约 3.3ms |
| 与 Shield 相同解密文件 | 1280×720 / 24 | 0.250～38.917 秒 | 0→77 | 约 225ms |

第二集是《我都元婴期了，你跟我说开学第四季》，时长 161.727 秒；两档从零开始，
未修改线程数、渲染缓冲尺寸或额外做性能调参。“540P”是接口/界面档名，
报告保留真实的 1024×576 尺寸，不把标签当成精确像素高度。

同文件对照为此前 Shield 的 61.875 秒 / 1485 帧 / 24fps 样本，
SHA256 `cd7525b9f7dba7ab29cdeea1a1b644c22a01f8df4851ebd5c36c7b9ac7483237`，
通过受限本地 HTTP 中继送入应用回环地址，无媒体上传。该组在约 28～32 秒片段
掉帧增加，不能写成 720P 全程流畅。

初次实际第一集 720P/30fps 观察到更严重的掉帧与约 3 秒时钟偏差。
但这次采样中含一次约 11 秒截图阻塞，不作为干净的性能对照；截图前已经存在
明显掉帧和偏差。不能把不同集/24fps/30fps 的结果混在一起推导固定性能。

## 基本操作

| 操作 | 实际结果 |
| --- | --- |
| 540P 画面 | 截屏核对视频画面可见，没有本轮可见的绿屏/花屏；截图在性能对照窗口外 |
| seek | 跳到 90 秒后继续播放，后续采样时间推进 |
| 暂停/恢复 | 暂停稳定在 119.333 秒，恢复后继续推进；恢复附近有短时掉帧/约 539ms 偏差，且此前截图可能重叠，不据此声称恢复完全平滑 |
| 手动上一集 | 第二集→第一集，实际 ByteVC2 540P 继续播放 |
| 自动下一集 | 第一集 seek 至片尾前 5 秒，让其实际结束；收到 1 次 `ended`，随后第二集继续播放，未伪造结束事件 |
| 后台/返回 | Home 后暂停、Surface 脱离；返回并显式播放后 Surface 恢复，时间继续推进 |
| 正常退出 | 确认原生“退出”，回到桌面；本测试包的 CoreService 和 Go 子进程停止，Android 可保留缓存 Java 进程 |

返回推荐时可能遇到 `VIDEO_MODEL_NO_QUALITY`：实验包故意只取 ByteVC2，
HEVC-only 条目会被测试过滤拒绝。这不是生产选源策略，也不是正式版故障证据。

## 边界与保留事项

- 未人工听音，仅检查 AudioTrack/AAC 状态和音画时钟；没有完成主观声画验收。
- 没有在 Zidoo 测 1080P、竖屏、多剧长时间循环或所有更低档位。
- 约 38 秒的良好片段不能证明整集、所有码流或所有旧设备流畅。
- 这证明 ARMv7 上的较低清晰度兜底有价值；不证明 1080P 问题的精确根因。
- 正式应用与数据保留；测试包退出，临时媒体中继/本机样本服务器和 WebView 转发已清理。
- [结构化证据](../scripts/bytevc2/evidence/2026-11-09-zidoo-mpv-preview.json)只含白名单诊断；
  媒体、截图、原始日志、身份、签名 URL、Token 和密钥均不提交。
