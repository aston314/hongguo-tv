# 桌面小窗播放

macOS、Windows、Linux 桌面版在播放控制区提供“小窗播放”。进入后，同一个主窗口切换为置顶小窗，沿用现有 WebView 和视频节点，不重新获取播放地址或重启播放。

- 支持暂停/播放、上一集/下一集、进度和音量调节。
- 从推荐进入时，可以切换上一部/下一部；独立剧集播放时禁用这两个按钮。
- 点击右上角返回按钮或按 Escape 返回大窗，恢复进入前的位置、大小及全屏/最大化状态。
- 保留用户调整过的小窗大小和位置；显示器配置改变时重新居中。
- 最小化仍按现有规则暂停，恢复后保留小窗模式。原生关闭按钮仍按原有退出确认流程处理。

Linux 的置顶效果取决于窗口管理器。窗口大小以操作系统窗口坐标计算；首开竖屏约 320×568，横屏约 480×300，可以手动调整。

验证分层：共享交互与状态隔离测试、窗口控制器竞态测试、真实数据浏览器切集/切剧、macOS 原生窗口模式验证，以及 GitHub Actions 的 macOS/Windows 构建和 Linux AppImage 播放检查。浏览器测试不代表所有桌面系统的编解码能力。
