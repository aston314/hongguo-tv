# 桌面播放區手勢與操作提示

桌面版在推薦與獨立播放頁提供相對於 `#hero` 的滑鼠操作；縮放視窗及進入全螢幕後仍使用同一套比例。

| 區域 | 操作 | 結果 |
| --- | --- | --- |
| 左側 28% | 雙擊 | 快退 10 秒 |
| 右側 30% | 雙擊 | 快進 10 秒 |
| 中央正方形 | 單擊 | 播放／暫停 |
| 其餘非互動空白區 | 單擊 | 隱藏／顯示文字及播放控制項 |

中央正方形邊長為畫面寬度的 22% 與高度的 36% 中較小者。左右單擊不改變播放狀態；中央及空白區雙擊只執行第一次單擊，避免立刻反轉操作。跨越左右區域的雙擊不觸發快轉。

按鈕、進度條、表單、連結、可編輯內容、對話框、底部控制列及目錄保留原有事件。修飾鍵、非主按鍵與鍵盤產生的 click 不觸發區域手勢。隱藏控制項後移動滑鼠不會立刻重新顯示，明確的控制項顯示操作可恢復原行為。

播放／暫停顯示 700ms 圓形圖示；快進／快退顯示 850ms 雙箭頭與「10 秒」。提示只來自手動操作，也適用原本共用的鍵盤播放／快轉路徑。播放成功且仍為相同來源才顯示播放圖示。提示層不接受點擊、不加入焦點鏈，重複操作重用節點並重設計時器。`prefers-reduced-motion` 會停用縮放動畫，保留短暫靜態提示。

此功能只在 `desktopShell` 啟用；不變更 Android 遙控器或 webOS 操作。沒有新增快取、下載、帳號、更新渠道或依賴。

## 驗證

```sh
node --check core/cmd/hongguotv/ui/playback-pointer.js
node --check core/cmd/hongguotv/ui/app.js
node --test tests/playback-pointer.test.cjs tests/episode-wheel.test.cjs tests/desktop-pointer-focus.test.cjs
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

手動驗證使用自有／測試影片：

1. 在一般視窗及全螢幕依序測左右雙擊、中央單擊及空白單擊。
2. 暫停時快轉應保持暫停；片頭不能快退到負值，片尾不能超出影片範圍。
3. 按鈕、進度條、對話框與側欄仍可操作；隱藏控制項後移動滑鼠不會重新顯示。
4. 快速重複操作，確認圖示不堆疊、會自動消失；啟用減少動態效果後不縮放。
5. 確認播放被阻擋時不出現成功圖示，裝飾層失敗也不妨礙播放控制。

macOS 的客製版本曾經實機驗證相同操作；本次對齊上游後另以隔離 WKWebView 驗證實際模組及 CSS 的四種提示、點擊穿透、焦點、過期計時與節點重用。這不代表整個上游 App 已重新完成實機驗收。Windows／Linux 桌面實機、長時間播放及音畫完整聽驗仍待驗證。
