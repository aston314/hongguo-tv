# 红果短剧 webOS 测试版 0.2.138

本版随统一主线更新版本号并重新打包；webOS 的播放、界面及账号行为没有功能变更。

- 继续保留空播放响应连续出现时有限预算更新匿名播放身份并重试的行为；不影响登录账号，也不对普通网络错误或解码错误换身份。
- webOS 继续使用原有竖屏黑边显示，不提供动态背景设置。

webOS 继续固定使用 Range/CENC 边播边下、唯一 HTML5 主视频元素及有限下一集预取；保留扫码和手机号登录。有声倍速仍以默认关闭的实验开关提供，开启后才显示播放器倍速入口。重试间隔不是请求总耗时上限，持续的上游故障仍会明确报错。

真实 webOS JS Service 预览已验证扫码登录、Service 重启后的身份恢复、历史/收藏同步、预约列表读取及搜索。自动化检查不替代 LG 实机扫码、切后台恢复、连续播放及音画同步验证；本包继续保持测试版渠道。

支持设置内在线检查更新及内置代理线路。应用仅检查并提示，不自动下载或安装 IPK；请启用电视 Developer Mode，通过 webOS Dev Manager 或 webOS 开发工具安装新版。
