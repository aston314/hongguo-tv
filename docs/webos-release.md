# 红果短剧 webOS 测试版 0.2.133

- 新增手机红果 App 扫码登录，账号页默认显示二维码，原手机号验证码、上行短信及 MFA 登录保留。二维码、设备注册、确认和 Cookie 由本机 JS Service 处理，登录后复用原有账号保存与云同步；离开页面、切后台或取消会结束旧扫码任务。
- 对齐共享 Go 核心的完整 Medusa 签名，并修复账号读取携带空校验头的问题。
- 修复追更与更新提醒之间的方向键焦点往返；更新提醒使用整行外框高亮，仅列表滚动，标题和返回按钮保持可见。

webOS 继续固定使用 Range/CENC 边播边下、唯一 HTML5 主视频元素及有限下一集预取；不启用 Android/桌面本次新增的整集预下载默认值和完整预下载切集过渡优化。有声倍速仍以默认关闭的实验开关提供，开启后才显示播放器倍速入口。

真实 webOS JS Service 预览已验证扫码登录、Service 重启后的身份恢复、历史/收藏同步、预约列表读取及搜索。自动化检查不替代 LG 实机扫码、切后台恢复、连续播放及音画同步验证；本包继续保持测试版渠道。

支持设置内在线检查更新及内置代理线路。应用仅检查并提示，不自动下载或安装 IPK；请启用电视 Developer Mode，通过 webOS Dev Manager 或 webOS 开发工具安装新版。
